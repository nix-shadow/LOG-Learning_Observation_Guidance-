THEORY OF CHANGE

Formative assessment works — when the teacher has time to act

  • • Formative assessment (Hattie: d≈0.4–0.9 range; feedback d=0.73) is among the strongest interventions — but it hinges on teacher capacity to respond.
  • • Nepal's CAS (Continuous Assessment System) is mandated but failing: "heavy workload, large class sizes, lack of formal training, insufficient time for documentation" (Mangal Research Journal 2025). Teachers see CAS as paperwork, not pedagogy.
  • • The 2025 CAS study's core finding: documentation burden crowds out the remedial teaching CAS was designed to trigger.
  • → LOG implication: the observation/guidance layer must automate the documentation so the teacher gets the remedial action, not the form-filling.
FRAMEWORKS

What good observation frameworks measure

  • • CLASS (Classroom Assessment Scoring System): emotional support, classroom organization, instructional support — the research backbone of classroom observation; correlates with learning gains when scored reliably.
  • • Early Warning Systems (EWS): attendance, behavior, course performance as predictors of dropout — the metric set LOG's learning-journey data maps onto directly.
  • • Error-pattern analysis (from formative-assessment research): diagnosing which misconception produced a wrong answer, not just "wrong" — this is what turns a quiz into guidance.
  • • Skills-based observation (e.g., ELP/reading-level bands): mastery bands instead of percentages — "approaching / meeting / exceeding" framing fits supportive language.
  • → LOG implication: guidance = attendance + practice + error-pattern → next-action. Never "you failed"; always "this area could use more practice."
MECHANICS

Assessment mechanics that survive field conditions

  • • Retrieval + immediate feedback is both the learning mechanism (g=0.50) and the formative signal — practice quizzes ARE the assessment engine.
  • • Mastery thresholds with re-quiz loops (Mindspark/adaptive pattern): repeat with varied questions until threshold, then advance — no permanent failures, honest progress.
  • • Per-learner status (LOG's roadmap item: per-learner activity status) is exactly the EWS data model — attendance + completion + score as time series.
  • • Authentic work samples (photo upload of notebook work — cheap on any phone) give teachers evidence where MCQ can't (Nepal's "checking copies" practice digitized).
  • • Anti-cheating by design: question banks with random selection + varied numerics beat fixed "Ten Sets Collections" that enable WhatsApp answer-sharing.

LAW

Nepal's privacy law landscape for children's data

  • • Privacy Act 2075 (2018): Nepal's general data-protection law — collection must be for a stated purpose, minimal, and with consent; sensitive personal data (incl. children's data in practice) gets stricter treatment; data breach notification duties.
  • • IT & Cybersecurity Bill 2082 (§61–62): criminalizes unauthorized access/exfiltration of personal data and provides for data-protection enforcement — a strengthening regime that will make edtech data handling a compliance matter, not a vibe.
  • • Children as a special category: international consensus (UNCRC Art. 16, GDPR Art. 8) treats children's data as higher-risk; Nepal's courts have referenced child-protection principles in data disputes.
  • • Schools are data controllers in practice: report cards, attendance, health notes, fee records — LOG holds this data for schools, so LOG is a processor with fiduciary obligations.
THE CAUTIONARY TALE

Respondus $6.25M biometric settlement — the anti-pattern

  • • Respondus settled a $6.25M class action over biometric data collection — face scans and fingerprints captured over 8 years without proper consent (Illinois BIPA-style claim).
  • • Students reported bricked computers from LockDown Browser (r/UniversityofArkansas warning, r/WWU 2026 thread).
  • • Proctoring tools "have serious bias problems… much worse at recognizing dark skin" (r/highereducation) — biometric proctoring is a fairness disaster for a country as diverse as Nepal.
  • • r/Professors on Canvas AI: "private student information via assignment extensions, extra quiz time, gradebook notes" — every stored datum is a potential training-data or leak vector.
  • → LOG implication: no cameras, no biometrics, no LLM training on learner data. Log only what's needed for guidance; delete on request; document retention.
LOG'S CURRENT POSTURE

Where LOG already stands — and the gaps

  • • ✅ No plaintext OTPs/passwords (bcrypt hashing), no plaintext auth in sync-queue (F2 fix rejects /auth/* offline queuing).
  • • ✅ JWT expiry + jti revocation, role re-validation on every request (demotion/soft-delete respected).
  • • ✅ Audit logging (auth.login, auth.logout, admin ops) — the foundation of data-usage accountability.
  • • ✅ No external LLM integrations — no learner data ever leaves for model training.
  • • ⚠️ Gaps to close: documented data-retention policy; deletion/export endpoints per user (child's guardian); consent records for guardian sign-off; breach-notification flow; privacy notice in Nepali + English.
  • • ⚠️ Sync-queue content: queued records contain learner answers — must be encrypted at rest in IndexedDB (today it's plaintext local storage; low risk locally, but a school-shared-device consideration).

INTEGRATION PATH

Recommended architecture: LOG as the guidance layer over Nepal's best content

  • • E-Pustakalaya / E-Paath via API partnership (OLE Nepal's redesign roadmap explicitly includes API integration; NGO-partner friendly — info@olenepal.org). CC BY-NC-SA allows reuse with attribution + non-commercial + share-alike; offline servers can be mirrored.
  • • CDC + NEB PDFs mirrored with a licensing memo (verify with CDC: ed@moecdc.gov.np) — the legal gap is the biggest obstacle, not the technical one.
  • • Sikai Chautari courses via Moodle REST web services — read access needs no account.
  • • Nepali Wikipedia via official Kiwix ZIM files bundled offline.
  • • Khan Academy: link-out only (no Nepali localization exists — verified) — a content gap LOG could itself fill with curriculum-aligned practice.
GAPS

The honest gaps in Nepal's OER ecosystem

  • • License fragmentation: E-Pustakalaya/KA are CC BY-NC-SA (non-commercial); CDC/NEB PDFs carry no explicit open license — a federated catalog needs a licensing memo per source.
  • • Interactive content ends at grade 8: E-Paath covers 1–8; grades 9–12 have only static PDFs + NEB samples. LOG's practice engine could be the interactive layer for 9–12.
  • • No Khan Academy Nepali — no big-brand adaptive math in Nepali; open lane.
  • • No shared metadata/API standard — LOG must build its own metadata layer (LOM-style tags, grade/subject/language indexing).
  • • Government content is online-only — no Kiwix-style distribution of official textbooks exists.

Design Rules distilled for LOG

RULE 01

Automate the CAS documentation

Nepal's CAS fails because paperwork crowds out remediation. LOG's observation layer must auto-generate the records so teachers act on them, not file them.

RULE 02

EWS data model: attendance + practice + scores

Early-warning signals are the guidance engine. LOG's per-learner activity status (roadmap item) is exactly this — complete the time-series so trends exist.

RULE 03

Error-pattern diagnosis, not just scores

Tag questions by misconception so guidance names the skill gap ("this area could use more practice") instead of reporting a number.

RULE 04

No biometrics, no cameras, no LLM training

The $6.25M settlement and bias evidence make proctoring-tech indefensible for children. LOG's anti-cheating = varied question banks, honest practice, no surveillance.

RULE 05

Guardian consent + deletion rights

Privacy Act 2075 + IT Bill 2082 §61-62 trend: build consent records and per-child data export/deletion endpoints now, before compliance is forced.

RULE 06

Retention policy + breach flow, documented

State retention windows (e.g., current school year + N) in a Nepali+English privacy notice; wire a breach-notification path into the audit log today.

RULE 07

Encrypt sync-queue at rest

Queued learner answers sit in IndexedDB on shared school devices. Encrypt local queue payloads — cheap, and closes the shared-device hole.

RULE 08

Integrate OLE Nepal, don't rebuild

9,361 books + 540+ modules + 1,700+ offline servers already exist. LOG's moat is guidance over content, not content itself.

RULE 09

Own the 9–12 interactive gap

No interactive curriculum content exists for grades 9–12 in Nepali — the SEE-exam lane. Practice questions for 9–12 are the clearest content opportunity in the country.

RULE 10

Licensing memo per OER source

CC BY-NC-SA vs no-CC-mark PDFs: LOG must record attribution + license per item in its own metadata layer (honesty principle applies to content provenance too).

RULE 11

Mastery bands, not percentages

"Approaching / meeting / exceeding" framing fits supportive language and avoids the GPA-comparison culture documented in parent research.

RULE 12

Digitize "checking copies" via photos

Notebook-photo uploads (works on any phone, offline-queueable) give teachers authentic evidence and parents visible work — replacing the paper diary without losing its role.
