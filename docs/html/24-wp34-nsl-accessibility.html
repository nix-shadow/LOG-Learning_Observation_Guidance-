NSL video captions

AC: core units captioned; NSL video content sourced with proper consent

What was implemented

  • • Activity.caption_text carries the NSL caption track; the lesson page renders a caption block only when the field is non-empty — no invented captions.
  • • act-4 (Electricity) seeded with a bilingual caption description (NSL text + EN gloss); catalog cards show an “NSL captions” badge for captioned units.

Proof

wp34t02 ✓

High-contrast & font-size packs

AC: user-adjustable font size and high-contrast theme; persisted locally

What was implemented

  • • lib/a11y.ts: FontScale (normal 1 / large 1.18 / xlarge 1.35), load rejects unknown stored values (honest fallback), apply sets data-font-scale / data-contrast on <html>.
  • • A11yProvider in the root layout applies persisted prefs at mount — no flash of the unstyled interface; works fully offline (localStorage only).
  • • Settings → Accessibility card: A/A/A font-size buttons + high-contrast switch; globals.css overrides lift muted text/border opacity under high contrast.

Proof

  • • src/lib/__tests__/a11y.test.ts — 5 tests: honest defaults, round-trip, unknown-value fallback, attribute application, scale ordering.
  • • frontend/src/app/settings/page.tsx + components/A11yProvider.tsx.
