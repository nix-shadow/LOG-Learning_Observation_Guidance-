OER metadata schema

AC: content model carries license + attribution fields; UI displays them

What was implemented

  • • Activity gains license / license_url / attribution / source_url (backend/internal/domain/domain.go).
  • • Strict allowlist OERAllowedLicenses: CC BY 4.0, CC BY-SA 4.0, CC BY-NC 4.0, CC BY-NC-SA 4.0, CC0, or “Own work (LOG team)” — with canonical deed URLs in OERLicenseURLs.
  • • Catalog cards render the license badge + attribution; lesson pages render a “Licensed under …” credit line. Nothing is shown when metadata is absent — honest, never invented.
  • • Seed backfills act-1..act-5 with “Own work (LOG team)” + LOG Learning Team attribution.

Proof

  • • frontend/src/app/learning/page.tsx + learning/[id]/page.tsx; src/lib/types.ts Activity fields.
  • • Allowlist exercised by backend/internal/handler/wp31_test.go.
wp31t02 ✓

Nepal OER import pipeline

AC: batch import of curated OER (CK-12-style packs) with license checks; downloadable for offline use

What was implemented

  • • POST /api/v1/admin/oer/import (oer_handler.go + oer_service_impl.go): per-row validation — missing id, unknown/empty license, and un-attributed third-party rows are rejected with a human reason; the rest still import.
  • • activityRepo.CreateMany imports in one transaction, skipping existing IDs so learner progress is never orphaned by a re-import.
  • • Every import writes an oer.import audit row with pack name + imported/skipped/rejected counts; route rate-limited (5/IP).
  • • Two seeded OER packs (act-11, act-12) — original LOG-authored content shared under CC BY-SA 4.0 with real attribution; offline use rides the existing fetchWithCache seam.

Proof

  • • backend/internal/handler/wp31_test.go — 3 tests: valid pack imports with stored metadata, re-import skips, unknown license + missing attribution rejected with reasons, nameless pack 400.
  • • backend/database/seed_phase3.go; docs/PARTNERSHIP_LANES.md §3/§4 for the rules.
