WP-2.1 — Parent Portal

The shipped record for the WP-2.1 work package (tracker tasks wp21t01–wp21t03, RC-04): guardian linking via teacher-issued codes with evidenced consent, a read-only progress digest with no sensitive raw data, and an opt-in digest toggle. Every acceptance criterion maps to code or a test below.

wp21t01 ✓

Parent invite/link flow

AC: guardian links to a learner via school verification; consent captured and recorded.

What was implemented

  • • ParentLink + ClaimParentLinkTx — a single transaction that creates the PARENT user, transitions pending→linked, and records the parent_access consent.
  • • POST /moderator/students/:id/parent-invite issues a teacher-verified 6-char one-time code; POST /auth/parent-signup claims it (rate limited 5/IP).
  • • disclosure_hash is required and validated — the sha256 of the exact bilingual notice text the guardian saw (PARENT_NOTICE_EN/NP); djb2-<hex> accepted on non-secure-context school LANs.

Proof

  • • wp21_test.go TestParentInviteAndClaim; login page "Parent · अभिभावक" tab; disclosureHash() in src/lib/crypto.ts.
wp21t02 ✓

Parent dashboard

AC: read-only progress digest; no sensitive raw data exposed (no OTPs, no contacts).

What was implemented

  • • GET /parents/children + /children/:id/digest — scoped to the caller’s linked children only.
  • • ParentChild = id + name + opt-in only; ChildDigest rebuilt from GetDashboardData with observations excluded; no contacts ever.
  • • /parent page gated to the PARENT role in middleware.ts; role-based landing after login; parent-only nav item.

Proof

  • • wp21_test.go TestParentDigestReadOnlySanitized; ParentPortal UI on /parent with honest empty/loading states.
wp21t03 ✓

Opt-in digest notifications

AC: email/SMS digest template reviewed for supportive tone; opt-in only.

What was implemented

  • • POST /parents/children/:id/opt-in — opt-in only, default off; digest_opt_in surfaced in the children list.
  • • Toggled in the /parent UI; the action is audit-logged (parent.opt_in); supportive copy in the parent namespace.

Proof

  • • wp21_test.go TestParentDigestOptIn; audit trail in the admin UI.
