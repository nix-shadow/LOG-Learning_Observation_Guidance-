wp24t01 ✓

Offline activity digest

AC: after reconnect, learner sees what synced; queued items surface with a confirmation.

What was implemented

  • • syncQueue writes {synced, failed, at} to log_reconnect_digest and dispatches log:digest-ready — a single choke point covering the window-online listener AND manual flushes.
  • • Written only when synced>0 || failed>0 — an honest zero state, never an invented summary.
  • • ReconnectDigest card on the dashboard ("Back online — changes synced: N · failed: M"), dismiss clears; helpers get/clearReconnectDigest in src/lib/api.ts.

Proof

  • • ReconnectDigest.test.tsx — 5 tests: event fire, pre-mount read, dismiss, zero state, helper round-trip.
