The case in one paragraph

Global LMS users rate their platforms 43–66/100 and say "each suck in their own way"; Nepal's government portal is online-only with role leaks; teachers rate their own LMS competency 1.39/5; only ~20% of schools have baseline internet; and the national exam culture demands practice, not surveillance. Meanwhile the evidence base shows exactly what works: offline-first content + retrieval practice + adaptive level-matching + teacher visibility + parent communication (M-Shule +0.46 SD at $22.70/SD; Funda Wande +0.5 SD; Mindspark +0.37σ; phone tutoring 0.89 SD/$100). LOG already has the architecture the giants lack — offline-first PWA with honest sync, real RBAC, honest zeros. This playbook closes the remaining gaps with evidence-ranked moves.

Report Cards 12

P0 · BUILD NOW

RC-01 — Per-learner activity status with a real guidance engine

Problem · evidence

Guidance must be derived from actual data (AGENTS.md §1) — but learners have no time-series of attendance + practice + scores, so guidance is thin. EWS frameworks prove attendance/practice/performance predict outcomes; Chimple shows outcomes hinge on teacher visibility; LOG's roadmap already lists per-learner activity status.

Solution

Complete the per-learner status: attendance, completion, best-score, error patterns → rule-based next-action ("This area could use more practice — try set B"). Teacher dashboard: "who needs what, this week." Honest zeros everywhere.

Effort: M · touches backend/service + dashboard + moderator roster · Aligns: EWS, Chimple, Mindspark evidence

P0 · BUILD NOW

RC-02 — Practice engine with retrieval + immediate feedback (SEE-first content)

Problem · evidence

SEE is the iron gate (512,471 candidates, 65.98% pass, 145,507 non-graded); tuition is near-universal; cheating is organized via WhatsApp; the interactive content gap for grades 9–12 is empty. Retrieval practice is the strongest learning mechanism (g=0.50); immediate feedback d=0.73.

Solution

Curriculum-aligned practice sets (SEE first) with varied random question banks, instant corrective feedback, mastery thresholds with re-quiz loops, offline-first (sync-queue already exists). Anti-cheating by variation, not surveillance.

Effort: L (content + engine) · Aligns: M-Shule +0.46 SD, Mindspark +0.37σ, E-Paath gap 9–12

P0 · BUILD NOW

RC-03 — Moderator first-run onboarding (5-minute, in Nepali, assumes zero LMS)

Problem · evidence

Teachers rate LMS competency 1.39/5; "training programs are not mandatory"; first impressions permanently bias ratings (38.7 vs 67.5); onboarding is the #1 praise driver in 2,000+ reviews (273 mentions); 85% of edtech implementations fail on conditions.

Solution

Guided 5-minute flow: create class → add students (CSV) → assign first activity → see student view. Bilingual, supportive language, video-in-Nepali option, offline-safe (PWA). A "teacher handbook" pack downloadable for zero-connectivity schools.

Effort: M · Aligns: G2 onboarding evidence, ETRI training gap, Sikai Chautari failure

P0 · BUILD NOW

RC-04 — Parent portal: attendance + progress + results (beats the paper diary)

Problem · evidence

"Systemic communication" is the top failure (34.1% of variance); study recommends a "digital parent portal (attendance, progress, exam results)"; parents judge by GPAs and textbooks; the incumbent channel is the paper diary.

Solution

Guardian view (new role or scoped share link): attendance, practice streaks, honest progress bands, school announcements. Recorded Nepali audio option for low-literacy parents. Offline: updates cached, synced when possible.

Effort: L · Aligns: F1000Research recommendation, paper-diary replacement, WhatsApp-comms reality

P0 · BUILD NOW

RC-05 — Privacy pack: guardian consent, deletion API, retention policy, Nepali+English notice

Problem · evidence

Privacy Act 2075 + IT & Cybersecurity Bill 2082 §61–62 tighten the regime; the $6.25M Respondus biometric settlement is the industry's cautionary tale; r/Professors rejects LLM data retention; LOG holds children's data as processor for schools.

Solution

Guardian consent record on enrollment; per-child export + deletion endpoints; stated retention windows; breach-notification flow wired to the existing audit log; privacy notice in Nepali + English; encrypt sync-queue at rest (shared devices).

Effort: M · Aligns: AGENTS.md §1 (no secrets), §4 (RBAC), audit-log foundation

P1 · NEXT QUARTER

RC-06 — Teacher's "who to call" workflow (operationalizes the best-cost intervention)

Problem · evidence

Phone tutoring: 0.89 SD per US$100 (Botswana RCT) and 3.4 LAYS/$100 (Philippines); the multi-country RCT includes Nepal; but teachers have no structured call list.

Solution

From real progress data, generate a weekly "learners who could use a call" list with what to practice together — supportive framing, 15–20 min call script. Works over voice or WhatsApp voice notes; zero extra data cost.

Effort: S-M · Aligns: RC-01 engine, WhatsApp reality, Nepal-included RCT

P1 · NEXT QUARTER

RC-07 — Content packs: E-Pustakalaya/E-Paath integration + curriculum-tagged metadata layer

Problem · evidence

9,361 books, 540+ modules, 1,700+ offline servers already exist (CC BY-NC-SA, API on OLE's roadmap); the gaps: no unified metadata, no 9–12 interactive, government PDFs online-only with no CC mark; E-Paath interactive ends at grade 8.

Solution

Metadata layer (grade/subject/language/LOM tags) over E-Pustakalaya/E-Paath via API partnership; content-pack download for offline (extend .logsync pattern); licensing memo per source; own the 9–12 interactive gap with practice sets (RC-02).

Effort: L · Aligns: DIKSHA .ecar pattern, Kiwix ZIM, AGENTS.md no-hallucination provenance

P1 · NEXT QUARTER

RC-08 — Gradebook honesty: weight math visible, one-entry, report-card generation

Problem · evidence

The #1 gradebook failure: silent misconfiguration (5-point quiz weighted like a 200-point final); "if it's not in Skyward, it's not real" — 2x work; CAS paperwork crowds out remediation; report cards are teacher time.

Solution

Show weight math on every grade (no silent defaults); single-entry — teacher enters once, everything derives; auto-generate CAS/report-card records from real data (supportive mastery bands, not GPA flaunting); CSV export with the existing sanitizer.

Effort: L · Aligns: r/Teachers evidence, Mangal Research CAS study, export_handler

P1 · NEXT QUARTER

RC-09 — Spaced-repetition scheduler + forgiving streaks

Problem · evidence

Distributed practice beats massed; streaks are the most replicated retention mechanic — when forgiving; gamification fails as decoration; engagement collapses without structure (<25% return).

Solution

SM-2-style scheduler over practice sets; streak freezes + "personal best" framing (no leaderboards); rewards tied to scheduled-review completion; honest offline state that queues and reconciles via sync-queue.

Effort: M · Aligns: learning science, Duolingo A/B, LOG honest-state principle

P2 · WATCH / PARTNER

RC-10 — QR codes on print materials (DIKSHA pattern)

Problem · evidence

Nepal is textbook-centric (parents gauge progress by textbooks); DIKSHA proved the print→digital bridge at 600M+ textbooks, 12B+ QR codes, fully offline.

Solution

Partner with a school/municipality: QR stickers on grade-10 materials → offline practice set. Pilot cheap, scales via schools printing their own. Requires content ready (RC-02).

Effort: S (pilot) · depends on RC-02 · Aligns: DIKSHA, textbook reality

P2 · WATCH / PARTNER

RC-11 — Community hubs & radio/TV complements

Problem · evidence

Ideas Box: +23% learning with offline servers + solar; Nepal's Radio Pathshala reaches 77 districts via community radio; Nepal has an IVR RCT (World Bank 2022) in LOG's exact context.

Solution

Partnership lane: serve content to Ideas-Box-style hubs and Radio Pathshala; expose practice content as IVR/SMS-compatible (M-Shule proves $2–5/learner/month economics) for feature-phone tail.

Effort: partner-led · Aligns: 0-connectivity reality, Nepal IVR RCT

P2 · WATCH / PARTNER

RC-12 — NSL / accessibility content integration

Problem · evidence

Nepali Sign Language resources exist (OLE Nepal G1–6; EAEN project in Surkhet); WCAG 2.2 AA is the floor; disabled students find mainstream LMS navigation hostile (r/Professors).

Solution

Integrate NSL-tagged content; reduced-motion + text-mode (also data savings); untimed practice modes; 44px targets and focus visibility. No overpromising on braille until a standard exists.

Effort: S-M · Aligns: WCAG 2.2, OLE NSL, honest-capability principle

The LOG thesis, after 16 agents

The global LMS market is a sea of clunky giants that users tolerate, not love. Nepal's education system is exam-driven, connectivity-poor, and underserved by every existing tool — including the government's own. The evidence says the winning formula is offline-first + retrieval practice + adaptive level-matching + teacher visibility + parent communication + honest data. LOG already owns the architecture half. The playbook's P0 cards close the product half. Nothing here requires violating a single core principle: no hallucinations, no fabricated fallbacks, no LLM content, no biometrics, supportive language throughout.
